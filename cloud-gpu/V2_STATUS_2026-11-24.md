## 2. 本轮修了什么（都已在本分支）

| 问题 | 现象 | 修法 |
| --- | --- | --- |
| 只上传 code_file | 所有冒烟/训练内核 7~8 s 就 ERROR | payload 源码 `repr()` 内联进 `entry_main.py`，运行时写 `/tmp/_payload.py` |
| `kaggle kernels status` 的 `QUEUED` 假象 | 已死内核永远显示 QUEUED，轮询永远不结束 | 轮询改读 `GetKernelSessionStatus` 原始 body（无会话时返回 `{}`），超时明确落为 `poll_timeout` |
| 3 h job 超时打断真实训练 | 首次 v2 训练在 relay 等满 3 h 被杀，内核其实还在排队 | job 预算提到 **300 min**（内核轮询预算 170 min） |
| 秘密提交会把整条队列重放 | 消费信封的提交也会触发 run-queue | 新增 gate：`cloud-gpu/secrets/**` 单一来源的 push 不跑队列 |
| 产物取回 | `download_kernel_output` 在已完成内核上返回空 | 用 `ApiListKernelSessionOutputResponse.log` + 文件自带预签名 `url` |

## 3. 当前运行的验收口径（跑完必须逐条核对）

内核会在 `/kaggle/working/v2_training_report.json` 写出报告，`status` 必须是
`COMPLETED_EXPLORATORY_V2_TRAINING`，且需满足：

1. `training_started: true` 且 `code_commit` 指向本分支的真实提交；
2. `dataset_version: positive_core_v2_strict`，正例 FASTA SHA-256 =
   `45e237b3fa347d4279e6eb9a19ffa74bd33fb27cf13bb7943f69e635d4389ae6`，
   私有 bundle SHA-256 = `e09c75018c983bdf449b8e46790e357f1e943cc42809abf911dbffeb6c0099bd`；
3. `metrics` 非空：5 seeds × 5 folds × 60 epochs，M1/M2 主模型、M3 仅对照/消融，
   报告 AUROC/AUPRC/MCC/sensitivity/specificity + 校准与置信区间；
4. `private_model_bundle` 有 `bytes`/`sha256`/`drive_file`，即权重、scaler 与 split
   只进私有 Drive，Git 里永远不出现二进制；
5. 报告自身声明探索性：16 个 strict 正例、test 只有 2 个正例，**不可**当作独立盲测或
   发表级性能，也**不可**把模型预测说成湿实验活性。

任一条不满足 → 不发布 v2，继续留在数据/训练阶段（见 §5）。

- 训练报告全绿（§3 五条）；
- `cloud-gpu/results/dualamp-v2-publish-<date>/` 下留脱敏发布包：指标表、阈值、

- 显式标注「探索性、n=16 正例、非发表级」，并在 README/CHANGELOG 同步；
- 以上齐备才允许 `v2.0.0` 之类的 tag 与 Release。

## 5. 真正卡住上限的问题：正例只有 16 条

strict 冻结（`auto_evidence_v2_1.0`）在 3,579 个候选里只认下 **16 条全文可核验的抗菌正例**，
其余 3,563 条判 `AUTO_UNRESOLVED_NO_EVIDENCE`。所以即使本轮训练成功，模型也只能算
可行性验证。要把 v2 做成能用的模型，下一步必须扩正例，而不是继续调模型：

1. **补全文可达性**：3,563 条未决里，先分类「全文不可达 / 序列无法映射 / endpoint 非细菌 /
   证据冲突」，优先攻克前两类（这是数量最大的两块）。
2. **多源交叉**：DBAASP / DRAMP / APD3 等结构化数据库里带 MIC 的条目，与 UniProt/文献
   DOI 交叉验证后进 strict 集；只有出处可核验的才算正例。
3. **实验阴性缺口**：当前负例是 UniProt 弱背景（不是实验证实的无活性）。
   需要引入带实测无活性记录的负例，否则 specificity 无意义。
4. **目标菌分布**：现在正例集中在少数菌种，需按菌种/菌株平衡，否则模型学到的是来源偏倚。
