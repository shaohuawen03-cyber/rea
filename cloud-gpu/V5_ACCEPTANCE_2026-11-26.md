# v5 验收线：什么叫「硕士论文可发表」

用户要求：v5 要「进一步到论文可发表」。
这一份把标准写死，**先定标准再看结果**，避免事后挑对自己有利的数字。

## 一、为什么不能只报 AUROC

已实测到的三件事，任何一条都足以让「只报 AUROC」的论文被拒：

| 现象 | 实测 | 出处 |
|---|---|---|
| 组成诱饵被接受 | v2.1 65–70%，v4 仍 16–18% | 全量评测 `v4_evaluation_gate.json` |
| 固定 1% FPR 下灵敏度腰斩 | 0.87 → 0.45–0.49 | `fixed_specificity_operating_points` |
| i.i.d. 与聚类切分差距 | AUROC 只动 0.04，但灵敏度动 0.4 | 同上 |

**AUROC 掩盖代价**。外部基准里 M2 的 AUROC 0.9668 很好看，但同一阈值下灵敏度只有 0.6342。
论文若只写 0.9668，审稿人一旦问「1% 假阳率下你抓到多少」，数字立刻塌一半。

## 二、v5 的五条联合门限（全部满足才算「可发表级」）

| # | 门限 | 阈值 | 现状（v4） | 依据 |
|---|---|---|---|---|
| A | 组成诱饵接受率（三模型全部门） | **< 0.10** | 0.4617 / 0.1713 / 0.1678 ✗ | 挑战层定义：诱饵真实阳性率 0% |
| B | 固定 1% FPR 下灵敏度 | **≥ 0.70** | 0.4845 / 0.4948 / 0.4536 ✗ | 固定特异度是唯一可跨数据集比较的操作点 |
| C | 外部跨源 AUROC（DBAASP 正例） | **≥ 0.90** | 0.9608 / 0.9668 / 0.9671 ✓ | 已达标，但负例同源，只能算「跨源正例」证据 |
| D | deep 模型 vs 组成-only 的 AUROC gap | **≥ 0.10** | +0.1430 ✓ | 配对 bootstrap，CI [0.0939, 0.1981] |
| E | 短肽（≤8 aa）AUROC | **≥ 0.85** | 0.8585 / 0.9070 / 0.9110 ✓（边界） | smORF 场景，本项目的真实用途 |

**A 与 B 是互相拉扯的**：v4 的证据显示把诱饵压下去时灵敏度就掉。这正是 v5 四臂要解决的问题。
如果 v5 最终只能做到「A 过、B 不过」或反之，**就必须在论文里把它作为一个明确的两难写出来**，
而不是选一个数字报。

## 三、无论如何都不能写进论文的说法

- ❌「模型可预测 MIC / 最低抑菌浓度」——数据集里 TIER_A_MIC = 0
- ❌「对革兰氏阴性菌有选择性」——99.96% 靶标是字面量 "bacteria"
- ❌「负例是实验证实的无活性肽」——是 UniProt 无注释片段，弱标签
- ❌「测试集与训练集同源泄漏已排除」——v4 用 3-mer 聚类，不构成去冗余
- ❌「外部独立验证通过」——负例同源，只有正例换源
- ❌「优于 XX 已发表模型」——没有在同一协议下重跑过任何对照模型

## 四、可以写进论文的说法（有实测支撑）

- ✅「在组成匹配诱饵对抗下，AUROC 从 0.98 降到 0.95，且这一降幅在三个模型上一致」
- ✅「固定 1% 假阳率下，灵敏度从 0.87 降到 0.45——这是本方法的主要代价，我们如实报告」
- ✅「跨源 DBAASP 正例上 AUROC 0.96+，且该外部集的氨基酸组成相对训练集系统性偏移
      （K +0.104 / R +0.077 / E −0.065），按 BIB 2022 的结论这属于不利于模型的漂移方向」
- ✅「短肽（≤8 aa）性能显著低于长肽（0.91 vs 0.99），与 smORF 文献中短序列高假阳性的报告一致」
- ✅「我们公开 15 个权重、全部阈值与评测脚本，任何数字可被重算」

## 五、v5 四臂的判读表（先写好，跑完直接填）

| 臂 | 改变量 | 若 A 改善且 B 不降 → 结论 | 若 B 下降 → 结论 |
|---|---|---|---|
| `v4_repeat` | 无（复现） | 复现成功，v4 数字可信 | 复现失败，v4 数字需重算 |
| `no_trainhn` | 去掉可训练诱饵 | 诱饵注入不是必需，改用其他机制 | 确认「诱饵注入 ↔ 灵敏度」存在真实 trade-off |
| `scram_only` | 换全新诱饵池 | 模型学到的是规则，不是记忆 | 模型记住了训练池 → 需要更大/更杂的诱饵池 |
| `matched_neg` | 负例组成带匹配 | 灵敏度损失源于负例组成偏移，可修 | 损失源于任务本身难度，不可修 |
