## 2. 复跑交付运行

```bash
# 队列里加一条 run（不要手改内核），env 留空
python3 - <<'PY'
import json, datetime as dt
p='cloud-gpu/jobs/queue.json'; q=json.load(open(p))
q['jobs'].append({"id":"dualamp-v2-1-full-rN-20261125","provider":"kaggle","mode":"run",
  "accelerator":"NvidiaTeslaT4","script_path":"cloud-gpu/jobs/dualamp_v2_1_train.py","script_args":[],
  "extra_pip":["gdown","requests","fair-esm","pyyaml","biopython","pandas","scikit-learn","matplotlib"],
  "serve_minutes":15.0,"wait":False,"timeout_sec":12600,"status":"pending",
  "created_at_utc":dt.datetime.now(dt.timezone.utc).strftime('%Y-%m-%dT%H:%M:%SZ'),
  "kernel_slug":"dualamp-v2-1-full-rN-20261125",
  "inline_json":{"V21_INPUTS_JSON":"cloud-gpu/jobs/v21_inputs.json"}})
open(p,'w').write(json.dumps(q,ensure_ascii=False,indent=2)+'\n')
PY
git add -A cloud-gpu/jobs/queue.json && git commit -m "chore(cloud-gpu): dispatch a v2.1 delivery run" && git push
```

然后加 `mode: status` 和 `mode: output` 两条轮询任务；`output` 会把
`v2_1_training_report.json` / `v2_1_training.log` 拉进 `cloud-gpu/results/<job_id>/`。

## 3. 出发布包

```bash
python3 cloud-gpu/jobs/dualamp_v2_1_publish.py dualamp-v2-1-full-rN-20261125
# → cloud-gpu/results/dualamp-v2-1-publish-<UTC date>/
```

档位判定（`decide_tier`）：
- `V2_1_VALIDATED` —— 所有 blocker 为空（目前不可能，组成挑战会挂）。
- `V2_1_EXPLORATORY` —— 训练完成 + 有指标，但有 blocker。
- `NOT_RELEASABLE` —— 训练未完成。

发布器不会替你把 blocker 说成通过。**要发正式版，先让组成挑战 PASS。**

## 4. 私有权重包（当前未送达）

脚本已经在打包后 `shutil.copy2(private_zip, out/)`，所以**只要交付运行成功、且 relay 把
上传 session 送进内核**，一次运行即可同时拿到报告和权重。当前卡点：

1. Kaggle 内核输出**不跨运行保留**，不能事后从另一个内核里拿上一轮的 zip。
2. `gpu-relay` 曾在上传任务未真正执行时就消费掉信封 → 内核里没有 session。
   `cfcae1e` 起 gate 前置，只有 `run_queue=true` 才 `git rm` 信封。
3. `V21_PACKAGE_ONLY=1` 的"仅重打包"路径依赖 `kernel_sources` 挂载上一轮输出，
   实测时有时无（`package-only mode needs a mounted prior output`），不适合当主路径。

**推荐做法**：重跑一次交付运行（§2），确认日志里出现 `private_model_bundle.bytes` 再收工。
若只想重打包，先确认内核输出目录里确实有
`runs/results/final_models/.../ *.pt`（否则报 `no trained checkpoint found for the private archive`）。

## 5. 发布动作清单（每次照做）

1. 生成发布包（§3），确认 `v2_1_release_summary.json` 的 `tier` 与 `release_blockers`。
2. commit + push 到当前分支；`git tag -a` 打标签，`gh release create --prerelease`。
3. 归档 zip 到 Drive，然后 **`make_private` + `list_permissions`** 复核只剩 owner。
4. 结果文档里必须显式写出 blocker，不得把探索性数字写成"验证过的性能"。
