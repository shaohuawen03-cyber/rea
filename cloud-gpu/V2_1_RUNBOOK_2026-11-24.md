## 3. 训练协议

- 包：`leanrea@f610dc00b1aec3ab948a5b77574af0e644259a13`，`dualamp-lite` V4 流水线（build → features → train → report）。
- 编码器：`fair-esm` `esm2_t12_35M_UR50D`，第 12 层，480 维；**mock 后端的结果不得发布**。
- 模型：M1/M2 为主，M3 为对照/消融；loss=bce。
- 种子：1–5；folds：5；epochs：60。
- 阈值：dev OOF；test 独立分组；同时报固定特异度操作点。
- 拆分：同源聚类（CD-HIT/MMseqs2 缺席时自动降级为 k-mer fallback，**必须在方法里写明**）。

## 4. 发布口径（硬规则）

发布档位由证据决定，脚本 `cloud-gpu/jobs/dualamp_v2_1_publish.py` 自动裁决：

| 档位 | 条件 | 能说什么 |
| --- | --- | --- |
| `V2_1_VALIDATED` | 训练完成 + 非 smoke + 冻结正例 ≥100 + test 正例 ≥100 + 5 seeds + 有校准表 + composition 挑战 `PASS` | 可以作为 v2.1 release，仍不得称湿实验验证 |
| `V2_1_EXPLORATORY` | 训练真实完成，但上述任一科学门槛未满足 | 只能发**显式标注限制**的探索性版本 |
| `NOT_RELEASABLE` | 训练未完成 / 无指标 | 不发 |

无论哪档，以下永远不变量：

1. 正例序列、权重、scaler、逐条预测**只进私有 Drive**，Git 只放聚合数字与 sha256。
2. 自动裁决**不是** PI 人工签字。
3. 原始数据共享只在运行窗口内临时 `anyone-with-link` 只读，结束立即 `make_private` 并 `list_permissions` 复核。
4. 失败就停在数据/训练阶段，不伪造完成。

## 5. 本轮验证顺序（已执行）

1. **CPU smoke**：400 正例 + 400 诱饵 + 2,000 负例片段，1 seed × 2 folds × 2 epochs，跑通四步并产出
   报告结构（`COMPLETED_V2_1_TRAINING`）。目的只是验证接线，数字无意义。
2. **正式运行**：全量 14,577 正例 + 20,000 负例 + 14,572 诱饵，5 seeds × 5 folds × 60 epochs，GPU。
3. **发布包**：`dualamp_v2_1_publish.py` 生成脱敏候选 + 档位裁决。
4. **权限收口**：`make_private` + `list_permissions`，并记录额度前后差。

## 6. 工程坑（本轮真修掉的，附症状 → 根因）

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 内核 7–8 s 早退，`training_started: false` | `kaggle kernels push`（script 模式）只上传 `code_file`，payload 没进去 | payload 内联进入口脚本 |
| 重试必失败：`bundle id ... required` | 信封是一次性的，被上一轮消费即删 | 输入改由 `cloud-gpu/jobs/v21_inputs.json` 承载；信封只留给单次上传 session |
| 内核读不到输入描述文件 | payload 在 `/tmp` 执行，不是仓库副本 | queue 条目 `inline_json` 把描述文件注入内核环境变量 |
| `features` 20 分钟后才失败且无日志 | 日志写在 `/tmp` 且异常分支不保留 | 日志直接写 `/kaggle/working/v2_1_training.log`，每步 flush+fsync，失败时把尾部打到控制台 |
| `features` 报 `No module named 'Bio'` | pin 版本 `biophys.py` 需要 biopython | `extra_pip` 补 biopython；pip 改成逐包安装并打印结果，失败立即退出 |
| 两小时 poll 超时且拿不到产物 | `kernels push --wait` 阻塞在排队 | `wait=false` 异步派发，另配 `status` / `output` 控制任务 |
| 固定特异度表里特异度 0.01 | 取位方向反了（应为最低负样本分往上走） | 改为「满足目标特异度的最敏感切点」，并有单调性单测 |
| composition 裁决被无关挑战集污染 | 把所有 challenge 行都算进上限 | 只统计 `scrambled` / `composition` / `decoy`，排除 `external` / `homolog` |
| 指标表读不到 | 实际文件是 `results/<run>/internal_test_metrics.csv` | 按真实文件名优先匹配，保留旧拼写兜底 |
