# v3 复现性核对（2026-11-26）

> 目的：验证 2026-11-25 发布的 v2.1 指标与权重是否与原始交付运行一致。
> 方法：在完全相同的冻结协议下做**第三次独立完整训练**（`dualamp-v3-repro-20261126`），
> 逐指标比对三次运行。所有数字由 `cloud-gpu/results/dualamp-v2-1-repro-check-20261126/repro_comparison.json` 生成。

## 1. 结论

| 判定 | 结果 |
| --- | --- |
| `auroc_identical_across_runs` | **true**（三次 AUROC 完全相同，spread = 0.0） |
| `calibration_identical` | **true**（Brier / ECE spread = 0.0） |
| `reproducible` | **true** |
| `composition_challenge_failed_in_all_runs` | **true**（三次一致失败） |

**流水线是确定性的，发布数字可信。** 但一致性不消除组成捷径这一实质缺陷。

## 3. 逐指标一致性

| 模型 | AUROC（r3 / r4 / v3） | Brier（三次） | 偏差 |
| --- | --- | --- | --- |
| M1 | 0.983225 / 0.983225 / 0.983225 | 0.05119 | AUROC 0，Brier 0 |
| M2 | 0.988944 / 0.988944 / 0.988944 | 0.03088 | AUROC 0，Brier 0 |
| M3 | 0.989307 / 0.989307 / 0.989307 | 0.03023 | AUROC 0，Brier 0 |

### 唯一的不一致点（已解释）

M1 在 r4 上 MCC = 0.84952，r3/v3 均为 0.84917；敏感度 0.8807 vs 0.8778。
AUROC 完全相同 → 排序能力一致；差异仅出现在 0.5 单点阈值上，有 1 条序列的概率恰在 0.5 附近，
浮点累加顺序导致其翻转。**headline 应引用 AUROC / Brier / ECE 与固定特异度操作点，而非 0.5 单点。**

## 4. 仍然失败的部分

组成挑战三次裁决均为 `FAIL_COMPOSITION_SHORTCUT`，诱饵被判阳性比例
r3 0.7015 / r4 0.7024 / v3 0.7015，判据 < 0.10。

**这不是发布失误，是模型缺陷**：模型主要依据氨基酸组成判断，而非序列顺序。
